## My approach

> A strong model is only part of a useful system.

- **Structure before scale:** reduce ambiguity and context overload before
  reaching for a larger model.
- **Evidence alongside outputs:** make it possible to inspect why an extracted
  value should be trusted.
- **Quality under constraints:** treat latency, memory, reproducibility, and
  deployment conditions as part of the modeling problem.
- **Research that survives contact with code:** turn experiments into typed,
  testable modules with explicit assumptions.
